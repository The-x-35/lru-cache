How this works

The cache runs in this page. Pages are real records in IndexedDB, so they survive a reload and evicting one really reclaims the space. A miss does genuine PBKDF2 work on a real Web Worker — the timings above are measured on your device, not scripted. The eviction policy is the same src/lru.js the test suite covers.

A web page cannot read your operating system's process table, so This browser uses what the browser genuinely knows instead: the assets this page actually loaded, weighted by their real transfer sizes. The self-hosted server build reads real processes.
